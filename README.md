# Regresión Lineal Simple por Mínimos Cuadrados (Java)

Implementación en Java del método numérico de Regresión Lineal Simple por Mínimos Cuadrados, incluyendo el cálculo del Coeficiente de Correlación de Pearson ($r$) y el Coeficiente de Determinación ($r^2$).

* **Asignatura:** SCC-1017 Métodos Numéricos (Unidad 5)
* **Institución:** Instituto Tecnológico Superior de Xalapa (ITSX)
* **Autor:** Mauro Josué Salazar García[cite: 7]

## Instrucciones de Ejecución
1. Clonar el repositorio.
2. Abrir el archivo `RegresionLineal.java` dentro de la carpeta del proyecto en IntelliJ IDEA[cite: 7].
3. Ejecutar el método `main` para ver los resultados en consola y la validación del modelo.
